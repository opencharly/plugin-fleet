# 2026.270.1554 — feat(fleet)!: drop the removed schema-version fields (schema-versioning removal)

## Summary

Drop the schema-version readers that the merged contracts removed, so `plugin-fleet` compiles and its module gate is green against **`sdk v0.2026270.1147` + `spec v0.2026270.938`**.

`spec#183` removed `version` from `#Deploy` and `#CandyRecord`; `sdk#313` changed `kit.ScaffoldCandy` and deleted the per-candy version arbiter. `plugin-fleet` still read the removed fields, which is the direct blocker of the `charly` host leg (opencharly/charly#714) — the host build failed at exactly two compiled-in plugins, this one and `plugin-box`.

Hard cutover — every removed reader deleted, no fallback:

- `candy/plugin-fleet/deploy_target.go` — drop `extra["version"] = req.Node.Version`; drop the `rec.Version = reply.Record.Version` and `rec.Version = ver` ledger writes (the venue path now passes `nil` to `kit.AddCandyDeploymentVia`, whose `update` callback is nil-guarded — evidence in §5).
- `candy/plugin-fleet/node_resolve.go` — drop the `node.Version` tag-propagation block; the resolved tag is the CLI `--tag` / a CalVer git tag only.
- `candy/plugin-fleet/node_resolve_test.go` — replace the deleted `node.Version` propagation test with `TestResolveNodeOverlays_ResolvesFromCLIAndNodeFields` (pins the new tag resolution + `refStr` + `addCandy` overlay).
- `candy/plugin-fleet/from_box_vm_test.go` — the fixture header no longer carries a `version:` stamp.
- `candy/plugin-fleet/migrate_ledger_candy_keys_test.go` — delete the `schema_version` read-path gate test (the gate went with the field in `sdk#313`).
- `go.mod`/`go.sum` — `sdk v0.2026269.1752 → v0.2026270.1147`, `spec v0.2026269.1640 → v0.2026270.938`.
