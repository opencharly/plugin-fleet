# 2026.272.2039 — fix(plugin-fleet): adopt the sdk ctx requirement on the deploy-config family

## Summary

`sdk#288` (`v0.2026271.915`) added a **`context.Context` parameter** to the `deploykit`
deploy-config family, removing the fail-open default so each invocation resolves its OWN
per-box overlay via `kit.DefaultDeployConfigPath(ctx)`. Without a bumped `sdk`, this plugin's
compiled-in candy cannot build against the `#717` fix version (`sdk v0.2026272.1813`), which
blocks `opencharly/charly#733` → `#714`. This PR adopts `ctx` in `plugin-fleet` and bumps
`sdk`/`spec` to the ctx-ready tags.

### Threaded the REAL ctx (no fabrication)

`plugin-fleet` is a compiled-in `command:deploy` plugin whose provider dispatches via
`Invoke(ctx, req)`. That genuine `ctx` is already stashed package-side by
`setCommandContext(ctx, exec)` at **every** op entry (`runDeployCommand`, `runDeployCompile`,
`runEphemeralRegister`, `runEphemeralTeardown`, `runDeployDispatch`) into the package var
`cmdCtx` — the SAME ctx every other `deploykit`/`loaderkit` seam call in the package already
passes (`loaderkit.LoadHostDeployConfigViaExecutor(cmdCtx, cmdExec)`,
`cmdExec.HostBuild(cmdCtx, …)`, `deploykit.BringUpMembers(cmdCtx, …)`). `context.Background()`
is **not** used in any production path — that would reintroduce exactly the cross-bed overlay
bleed `sdk#288` removed.

### Call sites changed (production)

| File | Call | Fix |
|---|---|---|
| `config_cmd.go` | `deploykit.SaveDeployConfig(...)` | `+ cmdCtx` |
| `config_cmd.go` | `deploykit.MutateDeployConfig(...)` | `+ cmdCtx` |
| `deploy_target.go` | `deploykit.SaveDeployState(...)` | `+ cmdCtx` |
| `deploy_target.go` | `deploykit.RemoveVmDeployEntry(...)` | `+ cmdCtx` |
| `load_executor.go` | `deploykit.LoadDeployConfig()` | `+ cmdCtx` |

Test call sites (which drive path resolution through `t.Setenv` — the process-env path, so the
`ctx` RunEnv overlay is irrelevant) pass `context.Background()`, exactly the idiom the sdk's
own `deploykit/loaddeployconfig_ctx_test.go` uses. Also updated the required-`ctx`
`SaveVmDeployState` (variadic → required) test call in `deploy_state_writer_test.go`.
