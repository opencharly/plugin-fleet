# 2026.286.0700 — fix(deploy): route by target CLASS, not by membership in a snapshot that degrades to nil (plugin-fleet#10)

## Summary

`compileNodePlans` decided whether to consult the box resolver with

```go
if target == "local" || c.externalSubstrates[target] {
```

— **membership in the loader-threaded `ExternalDeploySubstrates` snapshot**, which `fetchExternalSubstrates()` returns as `nil` on **three** separate failures (no exec seam, `HostBuild` error, JSON decode error). Indexing a nil map yields `false`, so a `vm:` deploy whose substrate was absent took the resolver branch.

Two outcomes followed, and the row's own reproduction is the milder one: the box-or-candy message after `charly vm build`/`vm create` on that same entity had both succeeded. **The worse one is measured here as a control in the new tests: with an envelope holding a candy named `omarchy-vm`, `resolveDeployRef(env, "omarchy-vm", …)` SUCCEEDS** — so the old branch could answer a VM with a same-named candy, not merely mis-word a failure.

**The change:**

- **`targetOnlyRoute` decides from the TARGET CLASS** — `imageBearingTargets`, the classifier the repo already held and used only for the message. `local` needs no substrate word; `pod`/`kubernetes` compile a primary image and take the resolver; **every other target is target-only**, and if its substrate is missing from a healthy set — or the set could not be read — it is **refused with the substrate message before any box or candy is consulted**. A future substrate gets this for free (the test is "not image-bearing", not a list).
- **`fetchExternalSubstrates` returns the reason** it could not read the set, `deployCmd` threads it, and **`routeTargetRef` is the ONE place the class decision and the resolver are joined** — which is what makes the ORDER testable, and the order *is* this row: refusal **before** resolution.
- **`annotateMissingSubstrate` is deleted** with the branch that needed it: the refusal now happens before the resolver, so the hint had become unreachable (R5 — no dead path left behind).
