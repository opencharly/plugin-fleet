# 2026.249.0728 — fix(fleet): clone distro inheritance — resolve the base VM's distro via the from: chain

## Summary

Clone distro inheritance (RCA 2026-09-06 — the omarchy#45 silent-skip). A `source.kind: clone` carries NO distro of its own — it IS the base VM (a COW overlay on the base's snapshot disk), so its distro IS the base's distro. `syntheticVmBoxFromEnvelope` resolves a clone's distro from the base VM via the from: chain (from_vm → deploy.from → VM entity → source.distro). Unresolvable → LOUD error, never a silent skip.

**The bug:** `buildVmSyntheticBox` resolved an EMPTY `img.Distro` for a clone → nil `DistroDef` → `CompileSystemPackageSteps` silently compiled ZERO package steps → the deploy-add step PASSED with nothing installed. The plan ALSO fell back to the HOST distro (cachyos) — the distro mixup.
